Security & Transaction Rules

To prevent market exploitation and secure local payments, absolute data integrity is locked down by database boundaries:

  • 🔑 Secure OTP Verification: Direct user session authentication via Twilio OTP prevents credential spoofing on the B2B direct mandi market.
  • 🛡️ P2P Escrow Ledger Locks: Firestore read/write structures require absolute UID equality. Farmers can only edit their uploads, and wholesalers can only write orders bound to their active buyer IDs.
  • 📈 Rate Cap Guard: Bids cannot deviate by more than 40% from standard verified market values to block price exploitation in remote village districts.
